## What's Included

- Modern dark / light mode UI with glassmorphism
- Sticky sidebar navigation + reading progress tracker
- Interactive quizzes, flashcards, collapsible sections
- Full lecture content: theory, diagrams (SVG), industry examples, labs, interview questions
- Self-contained — no external course platforms required

## Course Structure (30 Lectures)

| Module | Focus | Lectures |
|--------|-------|----------|
| 1 | Data Analytics Foundations & Pipeline | 1–4 |
| 2 | Advanced Data Cleaning & Preprocessing | 5–10 |
| 3 | Advanced Exploratory Data Analysis | 11–15 |
| 4 | Data Visualization & Storytelling + Power BI | 16–21 |
| 5 | Data Modeling & DAX | 22–26 |
| 6 | Capstone Project | 27–30 |

## How to Run Locally

Simply open `index.html` in any modern browser. No build step required.

- Pure HTML5 + CSS3 + Vanilla JavaScript
- Bootstrap 5 (CDN)
- No React, Vue, Node, or backend
