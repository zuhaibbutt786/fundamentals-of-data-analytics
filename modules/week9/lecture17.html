Lecture 17: Visualization Principles

Declutter, establish hierarchy, use color with purpose, annotate insights, and turn a chart into a clear story.

1. Learning Objectives

  • 1 Apply decluttering rules to remove non-data ink.
  • 2 Design visual hierarchy so the main message is seen first.
  • 3 Use color intentionally (categorical, sequential, diverging) and accessibly.
  • 4 Annotate charts so the insight is explicit, not left to guesswork.
  • 5 Structure a short visual story: context → finding → implication.

2. Declutter

Every extra line, grid, border, and label competes with the data. Remove what does not help the message.

  • Lighten or remove heavy gridlines
  • Avoid chart borders and 3D effects
  • Prefer direct labels over legends when space allows
  • Round numbers in labels when precision is not critical
  • Keep one primary message per chart

3. Visual Hierarchy

Guide the eye: title → key number or highlight → supporting series → footnotes. Hierarchy is both within one chart and across a dashboard page.

Practical hierarchy
  • Title — states the insight or question, not just “Sales”
  • Highlight — one series or point in a stronger color
  • Context — comparison period, target line, or average
  • Source / notes — small and secondary
  • Dashboard — KPI strip → main visual → driver breakdown → detail table
Website / learning analytics example
For this course site: top KPIs (active learners, completion %) → trend of weekly lecture opens → bar of modules with lowest quiz scores → table of specific lectures to improve. Same hierarchy applies to retail or healthcare dashboards.

4. Color with Purpose

Use casePalette typeExample
Distinct categoriesCategoricalRegion A, B, C
Low → high intensitySequentialSales volume heatmap
Deviation from midpointDivergingProfit vs loss; variance to target

Keep color-blind safe defaults (avoid pure red/green only). Limit categorical colors to ~5–7 distinct hues. Gray out non-focus series.

5. Annotation & Storytelling

Do not force the audience to hunt for the point. Call it out:

  • Label the peak, trough, or crossover
  • Add a short callout: “+18% after campaign launch”
  • Show a reference line (target, last year, average)
  • End with implication: what should change?
Story arc for one visual
Context (what/when) → Finding (what changed) → Why it matters (decision or next question)

6. Practical

A. Take a default software chart (busy grid, rainbow legend, generic title “Revenue”). Rewrite:

  1. A title that states the insight
  2. What to remove (declutter list)
  3. Which series to highlight and in what color role
  4. One annotation sentence

B. Website / course analytics: Design hierarchy for this course site’s learning data.

  1. KPIs: weekly active learners, quiz completion %, median time on lecture
  2. Main chart: weekly lecture opens (line)
  3. Breakdown: modules sorted by lowest average quiz score (bar)
  4. Detail: table of lectures with completion < 50%
  5. Write one insight title and one annotation for the main chart

7. Knowledge Check

Q1. Heatmap of sales volume by region and month is best with which palette?

A. Categorical rainbow
B. Sequential
C. Random hues
D. Only black and white hatching

8. Summary

  • Remove non-data ink; keep focus on the message.
  • Hierarchy: insight title → highlight → context → notes.
  • Color is a coding system, not decoration.
  • Annotate so the insight is explicit.
