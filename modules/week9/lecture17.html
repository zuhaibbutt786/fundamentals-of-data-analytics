Lecture 17: Visualization Principles

Declutter, visual hierarchy, color with purpose, and annotation — the craft layer that turns a correct chart into a clear decision tool.

1. Learning Objectives

  • 1 Declutter charts by removing non-data ink that does not support the decision.
  • 2 Apply visual hierarchy inside a chart and across a dashboard page.
  • 3 Use color semantically (categories, sequential, diverging) and accessibly.
  • 4 Annotate key points so the “so what” is explicit.
  • 5 Critique a visual using a principle-based checklist.

2. Motivation

Two charts can use the same encoding and still differ wildly in clarity. Principles — declutter, hierarchy, color discipline, annotation — separate amateur output from professional communication.

3. Real-World Story

The Rainbow Dashboard

A team shipped a dashboard with twelve colors, heavy gridlines, and no title hierarchy. Executives asked, “Where should we look?” After a redesign: neutral base, one highlight color for exceptions, KPI cards on top, and three annotations. Meeting time on interpretation dropped by half.

4. Declutter

  • Remove heavy borders, 3D, unnecessary gradients
  • Lighten or remove gridlines; keep only if they help reading values
  • Prefer direct labels over large legends when few series
  • Crop whitespace without crowding
  • Delete decorative icons that do not encode data
Data-ink idea
Maximize the proportion of ink that represents data. If removing an element does not reduce the ability to answer the question, remove it.

5. Visual Hierarchy

Inside a chart: title → primary marks → supporting reference lines → axes → footnotes.

On a page: KPI row → primary visual → secondary breakdowns → filters.

6. Color with Purpose

  • Categorical: distinct hues, few categories, colorblind-safe
  • Sequential: light→dark for low→high (single hue family)
  • Diverging: two hues around a meaningful midpoint (e.g., below/above target)
  • Reserve strong color for exceptions; keep baselines neutral

7. Annotation & Storytelling

Annotation answers “so what?” — mark the launch date, the threshold breach, the outlier cause. Titles should be conclusion-oriented when appropriate (“North region missed target by 12%”) rather than generic (“Sales by region”).

8. Hands-on Lab

  1. Take any bar chart and remove three non-essential elements.
  2. Rewrite the title as an insight sentence.
  3. Replace a rainbow sequential scale with a single-hue sequential scale.
  4. Add one annotation that a manager would need in a meeting.

Deep Dive — Visualization Principles

Professional analytics teams treat visualization as a product surface: every pixel should earn its place. The sections below expand theory, practice, and assessment so you can defend choices in a viva and in stakeholder meetings.

Use the same framing discipline from Lecture 4: decision first, metrics second, visual form third. Tool clicks in Power BI never replace that order.

LayerQuestionFailure mode if skipped
DecisionWhat changes if the viewer is right?Pretty charts nobody acts on
MetricWhat number proves progress?Vanity metrics and noise
EncodingWhich channel matches the task?Misread magnitudes
LayoutWhere should the eye go first?Scattered attention
InteractionWhat filters change the story?Static posters instead of tools

Extended Industry Patterns

E-commerce

Funnel visuals for checkout steps; cohort lines for retention; ranked bars for category contribution; KPI cards for conversion and AOV.

Healthcare

Sparklines for census; control-style lines for wait times; heat matrices for hour×day crowding; clear targets on KPI cards.

Banking

Waterfalls for P&L bridges; ranked bars for branch exceptions; trend + target bands for NPL; careful dual-axis avoidance.

Education / Course analytics

Completion by module as bars; weekly active learners as lines; drop-off funnels; heat views of engagement by weekday.

Step-by-Step Worked Example

  1. Frame: “We need to decide which product line to prioritize in next month’s campaign.”
  2. Metrics: Revenue, margin %, growth vs prior period.
  3. Intent: Rank lines by opportunity (growth × margin) and show trend context.
  4. Encoding: Position/length for rank; line position for trend.
  5. Charts: Sorted bar for current opportunity score; small line or sparkline for 12-week revenue.
  6. Design: Title states the decision; annotate top 3; source footer.

Anti-Patterns to Reject

  • Dashboard as a dumping ground for every available field
  • Default tool colors without semantic meaning
  • Truncated axes that exaggerate small gaps without disclosure
  • Legends that force eye travel across the whole page
  • Interactions that reset filters unexpectedly
  • Exporting screenshots with no date or filter context

More Flashcards

Declutter means?
Remove non-data ink that does not support the decision
Semantic color?
Color carries meaning (e.g., red = risk), not decoration
Small multiples?
Same chart repeated by category for easy comparison
Power Query role?
Shape and clean data before modeling and visuals

Extended Cheat Sheet

  • Decision → metric → encoding → chart → layout → interaction
  • Declutter; hierarchy; semantic color; annotate the “so what”
  • Advanced forms only when they answer a real question
  • Import → types → relationships → measures → visuals
  • Test: 10-second answer test + accessibility grayscale test

True / False

  • More charts always mean better dashboards. (False)
  • Direct labels often beat distant legends. (True)
  • Power BI visuals fix bad data models automatically. (False)
  • Filters should reflect real decision segments. (True)
  • 3D charts improve accuracy of comparison. (False)

Fill in the Blanks

  1. Visual ________ guides the eye to what matters first.
  2. ________ multiples repeat the same chart across categories.
  3. Power ________ is the ETL surface inside Power BI.
  4. A ________ card shows a single KPI prominently.

Answers: hierarchy; Small; Query; KPI

Summary

  • Declutter non-data ink; strengthen hierarchy; use color with meaning; annotate the insight.
  • Principles apply equally in Python plots and Power BI visuals.
