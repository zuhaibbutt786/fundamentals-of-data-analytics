Lecture 12: Correlation & Relationships

Pearson vs Spearman, correlation matrices, multicollinearity, and heatmap analysis — as specified in the syllabus and correlation course materials.

1. Learning Objectives

  • 1 Distinguish Pearson (linear) from Spearman (rank/monotonic) correlation.
  • 2 Build and interpret a correlation matrix for numeric features.
  • 3 Explain multicollinearity and why it matters for regression-style models.
  • 4 Create a correlation heatmap in Python and state actionable insights.
  • 5 Avoid mistaking correlation for causation in stakeholder communication.

2. Pearson vs Spearman

PearsonSpearman
MeasuresLinear associationMonotonic association (ranks)
AssumptionsRoughly linear; sensitive to outliersFewer distribution assumptions; robust to monotone transforms
Range−1 to +1−1 to +1
Use whenLinear relationships expectedSkewed data, ordinal vars, non-linear but monotone links

\[ r_{xy} = \frac{\sum (x_i-\bar{x})(y_i-\bar{y})}{\sqrt{\sum (x_i-\bar{x})^2\sum (y_i-\bar{y})^2}} \] Spearman is Pearson applied to ranks.

3. Correlation Matrix

A symmetric table of pairwise correlations. Diagonal = 1. Use it to:

  • Spot redundant features (very high |r|)
  • Find promising predictors of a target
  • Guide which pairs to scatter-plot next
Rule of thumb for |r|
~0–0.3 weak · 0.3–0.7 moderate · 0.7–1 strong (context-dependent; always plot).

4. Multicollinearity

When predictors are highly correlated with each other, regression coefficients become unstable and hard to interpret. Detection:

  • High pairwise |r| among predictors
  • Variance Inflation Factor (VIF) — VIF > 5 or 10 often flags concern

Remedies: drop/combine features, use dimensionality reduction, or regularization (conceptual for this course stage).

5. Python — Heatmap Practical

import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

df = pd.read_csv("../../datasets/sample_accidents.csv")
num = df[["speed_limit", "vehicles", "casualties"]]

pearson = num.corr(method="pearson")
spearman = num.corr(method="spearman")

sns.heatmap(pearson, annot=True, cmap="RdBu_r", center=0, vmin=-1, vmax=1)
plt.title("Pearson correlation — accidents sample")
plt.tight_layout()
plt.show()

# Pair to inspect
sns.scatterplot(data=df, x="vehicles", y="casualties")
plt.show()

Insight pattern: more vehicles in an incident often associate with higher casualties — check strength, then ask whether road type or speed confounds the relationship.

8. Summary

  • Pearson: linear; Spearman: ranks / monotone.
  • Matrix + heatmap = fast relationship scan.
  • Multicollinearity destabilizes multi-predictor models.
  • Correlation ≠ causation — always.
