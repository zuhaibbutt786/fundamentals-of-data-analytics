Lecture 29: Final Dashboard Completion

Finish the Power BI (or equivalent) dashboard: star model, measures, pages, interactions, and performance polish — syllabus “Final Dashboard Completion.”

1. Learning Objectives

  • 1 Load cleaned tables into a star-style model with correct relationships.
  • 2 Implement proposal KPIs as explicit measures (including at least one comparison such as YoY or % of total).
  • 3 Design 1–3 pages with clear visual hierarchy for the stakeholder.
  • 4 Add slicers, cross-filtering, and readable titles.
  • 5 Run a final QA pass (numbers, performance, accessibility basics).

2. Model Build (Module 5)

  • Fact table at the grain of your events/transactions
  • Dimensions: date (marked), entity, product/category, geography, etc.
  • 1:* relationships; single filter direction unless justified
  • Hide technical keys; friendly names

3. Required Measure Set

  • Base totals for each primary KPI
  • At least one time comparison (YTD, YoY, or prior period)
  • At least one ratio (rate, margin, average)
  • Optional: ranking or contribution % measures

Use DIVIDE, CALCULATE, and VAR patterns from L23–L24. Name measures so viva questions are easy to answer.

4. Page Blueprint

PagePurposeTypical visuals
OverviewAnswer the main decision at a glanceKPI cards, trend, top segments
Deep diveExplain driversBreakdown bars, matrix, scatter
Actions (optional)Exceptions / next stepsFiltered table, conditional formatting

5. Final QA Checklist

  • ☐ KPI totals match a known sample (Excel/Python check)
  • ☐ Slicers filter all intended visuals
  • ☐ No blank misleading totals from bad relationships
  • ☐ Performance acceptable (remove unused columns if slow)
  • ☐ Color contrast readable; title = insight
  • ☐ Data refresh path documented

6. Deliverable

  1. Power BI file (.pbix) or equivalent interactive dashboard
  2. One-page measure dictionary
  3. Screenshot of model view (relationships)

7. Knowledge Check

Q1. Capstone dashboard measures should primarily:

A. Duplicate every raw column as a measure
B. Implement proposal KPIs with clear comparisons
C. Avoid any time intelligence
D. Hide all slicers permanently

8. Summary

  • Model → measures → pages → QA.
  • Every visual should help the stakeholder decide.
