Lecture 28: Capstone Project Lab

Turn your proposal into analysis-ready data and first insights. This lab integrates Modules 2–4 plus the Ethics checklist from L27.

1. Learning Objectives

  • 1 Execute a complete cleaning + profiling pass on your Capstone dataset.
  • 2 Produce a short EDA that answers your problem statement.
  • 3 Draft first visuals that support your KPIs.
  • 4 Apply the Ethics checklist and document limitations early.

2. Recommended Domains (Syllabus)

  • Retail / e-commerce sales performance
  • Healthcare operational or outcome metrics (de-identified)
  • Transport / accident or safety analysis (course sample_accidents.csv is available)
  • Banking / credit or transaction patterns (public or synthetic only)
  • Education or HR people analytics (strict privacy rules)

Prefer public or provided datasets. If using organisational data, obtain written permission and strip personal identifiers.

3. Cleaning Checklist (Module 2)

  1. Load data → .info(), .describe(), missing rates, duplicates.
  2. Classify missingness (MCAR / MAR / MNAR) for key columns; decide delete vs impute; create “was_imputed” flags.
  3. Handle outliers (document keep / cap / remove decisions).
  4. Standardise types, categories, and date columns.
  5. Engineer 2–4 high-value features that answer your question (L8).
  6. Save a clean parquet/csv and a short data-dictionary note.

4. EDA Checklist (Module 3)

  1. Univariate distributions for every KPI-related variable.
  2. Bivariate relationships (correlation, group comparisons) that test your hypotheses.
  3. Time trends if dates exist (L14 patterns).
  4. At least one “interesting but expected” finding and one “surprising” finding.
  5. Note any bias or coverage issues discovered during EDA.

5. Visualisation Checklist (Module 4)

  1. One clear KPI card / summary number for the primary metric.
  2. One trend chart (time) if applicable.
  3. One comparison chart (category / region / segment).
  4. One relationship or distribution chart that supports a claim.
  5. Titles, axis labels, and source note on every visual.

6. Ethics Integration (from L27)

  • Write 5–8 bullet “Limitations & Ethics” notes (data gaps, possible bias, privacy steps taken).
  • Confirm no personal identifiers remain in the working file or screenshots.
  • Avoid causal language in any draft insight statements.

7. Lab Outputs to Keep

  • Clean dataset + short data dictionary
  • EDA notebook or script with key plots
  • Draft insight list (3–5 bullets) linked to visuals
  • Ethics & Limitations draft
  • Time log (helps you plan L29)

8. Suggested Timebox

ActivitySuggested share
Profiling + cleaning30–35 %
Feature engineering + EDA30–35 %
First visuals + insight drafting20 %
Ethics notes + documentation10–15 %

9. Summary

By the end of this lab you should have clean data, evidence-based insights, draft visuals, and an ethics note — ready for the modelling and dashboard work in L29.
