Lecture 28: Project Lab

Execute cleaning, EDA, and visualization on your approved proposal dataset — syllabus lab focus for the capstone.

1. Learning Objectives

  • 1 Clean the chosen dataset to a documented, analysis-ready state.
  • 2 Complete descriptive, correlation, grouped, and time-based EDA linked to KPIs.
  • 3 Produce a first set of decision-oriented charts (not decorative plots).
  • 4 Log every major transformation for the viva.
  • 5 Exit the lab with files ready for Power BI / dashboard modeling.

2. Cleaning Checklist (Module 2)

  • ☐ Profile: info, missing rates, duplicates, key uniqueness
  • ☐ Types & dates parsed correctly
  • ☐ Missing data strategy recorded (MCAR/MAR/MNAR thinking)
  • ☐ Outliers reviewed (IQR/Z); keep true rare events with notes
  • ☐ Scaling/encoding only where needed for later models
  • ☐ Feature engineering: ratios, calendar fields, bins tied to KPIs

3. EDA Checklist (Module 3)

  • ☐ Center, spread, skew, kurtosis for core measures
  • ☐ Correlation / multicollinearity scan for numeric drivers
  • ☐ Groupby / pivot by the segments in your proposal
  • ☐ Time trend + moving average if dates exist
  • ☐ Written findings: 5–8 bullets that answer KPI questions

4. Visualization Checklist (Module 4)

  • ☐ One chart per major question (trend, rank, composition, relationship)
  • ☐ Titles state the insight, not only the chart type
  • ☐ Consistent colors; decluttered axes
  • ☐ Export clean tables/CSVs for Power BI import

5. Lab Outputs to Keep

  1. cleaned_dataset.csv (or partitioned tables)
  2. Notebook or script with reproducible steps
  3. EDA insight note (1–2 pages)
  4. Chart pack or image exports
  5. Open issues list for dashboard phase

6. Suggested Timebox

0–30 min

Reload proposal; confirm grain and KPIs.

30–90 min

Cleaning + quality log.

90–150 min

EDA + insight bullets.

150–180 min

Core charts + export for dashboard.

7. Knowledge Check

Q1. Capstone lab success means:

A. Random charts with no notes
B. Deleting all outliers silently
C. Clean data, KPI-linked EDA, and documented steps
D. Skipping the proposal entirely

8. Summary

  • Lab = execute Modules 2–4 on your data.
  • Everything you change should be explainable in the viva.
