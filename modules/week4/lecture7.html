Lecture 7: Data Transformation

Min-Max normalization, Z-score standardization, log transformation, and categorical encoding — with Python labs, industry examples, and downloadable datasets aligned to the course sequence.

1. Learning Objectives

  • 1 Apply Min-Max scaling to map features into a [0, 1] range and understand its sensitivity to outliers.
  • 2 Standardize features with Z-score (mean 0, SD 1) and know when it is preferred over Min-Max.
  • 3 Use log (and log1p) transforms for right-skewed positive variables and measure the impact on skewness.
  • 4 Encode categorical variables correctly (label / one-hot / ordinal) and avoid common leakage mistakes.
  • 5 Decide when scaling is required (distance/gradient methods) vs optional (tree-based models).

2. Motivation — Why Transformation Matters

Raw columns almost never arrive in a form that algorithms or even simple comparisons like. Salary in PKR, age in years, and number of claims sit on completely different scales. Distance-based methods (k-NN, k-means, SVM with RBF) and gradient-based optimizers treat the largest-scale feature as the most important. Transformation puts every variable on a fair footing and often stabilizes variance so that correlations and models behave sensibly.

💡 Key Insight
Transformation is not cosmetic. It is part of making the analysis reproducible and the model trustworthy. Always document which transform you applied and fit scalers only on the training portion of the data (preview of Lecture 9).

3. Real-World Story

The Retail Pricing Model That Favoured Expensive Items

A mid-size e-commerce team built a simple similarity engine to recommend “customers who bought this also bought…”. Because unit price was left in raw form (ranging from 50 PKR to 250 000 PKR) while quantity sat between 1–20, the distance metric was dominated by price. Cheap, high-volume accessories never appeared near expensive electronics even when the same customers bought both. After Min-Max scaling of price and a log transform of quantity, the recommendations became sensible and conversion on the “Frequently bought together” widget rose 11 %.

4. Normalization (Min-Max)

The fitted training minimum and maximum map the training range into [0, 1]. Unseen values can fall outside that range unless clipping is enabled:

\[ x' = \frac{x - x_{\min}}{x_{\max} - x_{\min}} \]

When to use: neural networks, image pixel intensities, or any algorithm that expects bounded inputs. Caution: a single extreme outlier becomes the new max and compresses every other value toward zero. Always inspect the distribution (or clip outliers first — Lecture 6) before applying Min-Max.

Python (scikit-learn)
from sklearn.preprocessing import MinMaxScaler
scaler = MinMaxScaler()
df[["price_mm"]] = scaler.fit_transform(df[["price"]])

5. Standardization (Z-score)

Centers the variable at zero and scales it to unit variance:

\[ x' = \frac{x - \bar{x}}{s} \]

Here the scale must use the chosen variance convention. StandardScaler uses population variance (ddof=0). Scaling supports distance calculations, regularization, PCA variance comparisons, and optimization. Linear regression, logistic regression, and PCA do not generally require Gaussian input features. Standardization preserves shape and remains sensitive to outliers.

6. Log Transformation

Many real-world counts and monetary values are right-skewed (long right tail). Taking the logarithm compresses large values and often makes the distribution closer to normal, which improves the behaviour of correlation, linear models, and residual plots.

  • Use np.log(x) only when every value is strictly positive.
  • Use np.log1p(x) (= log(1+x)) when zeros are present (very common with quantity or claims).

After the transform, always re-check skewness:

print("Original skew:", df["casualties"].skew())
df["casualties_log"] = np.log1p(df["casualties"])
print("Log skew:", df["casualties_log"].skew())

7. Encoding Categorical Variables

MethodUse whenNotes
Ordinal encodingOrdered categories (Low / Medium / High, education level)Preserves rank; do not use on nominal data
One-hot (dummy) encodingNominal categories (region, weather, product type)Creates one binary column per category; drop first if needed to avoid multicollinearity
Frequency / Count encodingHigh-cardinality nominal (city, SKU)Replace category by its frequency; careful with leakage
Target encodingHigh-cardinality + supervised taskPowerful but must be done inside cross-validation folds
Common Mistake
Fitting any encoder (or scaler) on the whole dataset before a train/test split leaks information from the test set into the training representation. Always fit on train only, then transform both train and test.

8. When Is Scaling Required?

  • Required / strongly recommended: k-NN, k-means, hierarchical clustering, SVM with RBF kernel, PCA, neural networks, gradient-descent optimizers, regularized linear models (Ridge/Lasso).
  • Optional / usually unnecessary: tree-based models (Decision Tree, Random Forest, Gradient Boosting, XGBoost) — they split on thresholds and are generally insensitive to positive affine scaling; nonlinear transforms can alter fitted split thresholds.

import pandas as pd
import numpy as np
from sklearn.preprocessing import MinMaxScaler, StandardScaler

# Load from course datasets
df = pd.read_csv("datasets/sample_sales.csv")
print(df.head())
print(df.dtypes)

# Numeric columns we will scale
num_cols = ["Quantity", "UnitPrice", "Discount"]

# Descriptive demonstration only: no held-out prediction is evaluated here.
# For predictive evaluation, use the training-only pipeline in L9–L10.
# 1. Min-Max
minmax = MinMaxScaler()
df_mm = df.copy()
df_mm[num_cols] = minmax.fit_transform(df[num_cols])
print("Min-Max ranges:\n", df_mm[num_cols].agg(["min","max"]))

# 2. Z-score
z = StandardScaler()
df_z = df.copy()
df_z[num_cols] = z.fit_transform(df[num_cols])
print("Z-score means & stds:\n", df_z[num_cols].agg(["mean", lambda x: x.std(ddof=0)]))

# 3. Log transform of a skewed monetary column
df["UnitPrice_log"] = np.log1p(df["UnitPrice"])
print("Original UnitPrice skew:", df["UnitPrice"].skew().round(3))
print("Log UnitPrice skew:", df["UnitPrice_log"].skew().round(3))

# 4. One-hot encode Category and Region
dummies = pd.get_dummies(df[["Category","Region"]], prefix=["cat","reg"])
df_enc = pd.concat([df, dummies], axis=1)
print("Columns after one-hot:\n", df_enc.columns.tolist())

13. Flashcards

Min-Max formula?
(x − min) / (max − min) → [0,1]
Z-score formula?
(x − mean) / std → mean 0, variance 1
When log1p?
Right-skewed positive data that may contain zeros
One-hot vs Label?
One-hot for nominal inputs; OrdinalEncoder with explicit ordering for ordinal inputs; LabelEncoder for target labels.

14. Cheat Sheet

  • Min-Max: [0,1], sensitive to outliers
  • Z-score: mean 0 / SD 1, preferred for different units
  • Log / log1p: right skew, counts, money
  • Encoding: ordinal → explicit ordered codes; nominal → one-hot; high-card → frequency/target (careful)
  • Rule: fit scalers & encoders on train only
  • Trees: usually do not need scaling

15. Summary

  • Min-Max → [0,1]; Z-score → mean 0, SD 1.
  • Log (or log1p) for right-skewed positive variables; always re-check skew.
  • Encode categoricals correctly; never fit transformers on the full dataset before splitting.
  • Distance and gradient methods need scaling; tree methods usually do not.
