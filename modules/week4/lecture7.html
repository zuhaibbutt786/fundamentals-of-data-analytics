Lecture 7: Data Transformation

Min-Max normalization, Z-score standardization, log transformation, and categorical encoding — with Python scaling practice from the syllabus.

1. Learning Objectives

  • 1 Apply Min-Max scaling to a [0, 1] range.
  • 2 Standardize features with Z-score (mean 0, SD 1).
  • 3 Use log transforms for right-skewed positive variables.
  • 4 Encode categorical variables (label / one-hot) appropriately.
  • 5 Know when scaling is required (distance-based methods) vs optional (tree models).

2. Normalization (Min-Max)

\[ x' = \frac{x - x_{\min}}{x_{\max} - x_{\min}} \] Maps values into [0, 1]. Sensitive to outliers (min/max can be extreme).

3. Standardization (Z-score)

\[ x' = \frac{x - \bar{x}}{s} \] Centers at 0 with unit variance. Preferred when features have different units (speed vs count).

4. Log Transformation

For positive right-skewed measures: np.log1p(x) (handles zeros). Compresses long tails so models and correlations behave better (links to L11 shape content).

5. Encoding Categorical Variables

MethodUse whenNotes
Label encodingOrdinal categories (Low/Med/High)Implies order
One-hot encodingNominal categories (region, weather)Creates binary columns
Frequency / targetHigh cardinality (advanced)Careful with leakage

6. Python — Scaling Practical

import pandas as pd
import numpy as np
from sklearn.preprocessing import MinMaxScaler, StandardScaler

df = pd.read_csv("../../datasets/sample_accidents.csv")
num = df[["speed_limit", "vehicles", "casualties"]].copy()

minmax = MinMaxScaler()
num_mm = pd.DataFrame(minmax.fit_transform(num), columns=num.columns)

z = StandardScaler()
num_z = pd.DataFrame(z.fit_transform(num), columns=num.columns)

df["casualties_log"] = np.log1p(df["casualties"])
dummies = pd.get_dummies(df["weather"], prefix="weather")

7. Practical

  1. Min-Max and standardize speed_limit and vehicles; compare ranges.
  2. Log-transform casualties; recompute skew.
  3. One-hot encode weather or region.

9. Summary

  • Min-Max → [0,1]; Z-score → mean 0, SD 1.
  • Log for right skew; encode categoricals before most ML models.
  • Fit scalers on train only in real pipelines (preview of L9).
