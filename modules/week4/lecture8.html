Lecture 8: Feature Engineering Basics

Derived columns, aggregation, date-time extraction, and binning — syllabus practical: revenue, profit margin, monthly trends (and the same ideas on accident severity features).

1. Learning Objectives

  • 1 Create derived columns from existing fields (ratios, flags, interactions).
  • 2 Aggregate to new grain when the question needs it.
  • 3 Extract year, month, day-of-week, and similar from dates.
  • 4 Bin continuous variables into meaningful bands.
  • 5 Build features that answer a business question, not just inflate columns.

2. Derived Columns

# Sales-style (syllabus examples)
df["revenue"] = df["qty"] * df["unit_price"]
df["profit_margin"] = (df["revenue"] - df["cost"]) / df["revenue"]

# Accident-style
df["high_casualty"] = (df["casualties"] >= 2).astype(int)
df["vehicles_per_casualty"] = df["vehicles"] / df["casualties"].replace(0, np.nan)

3. Aggregation Features

Roll events up to customer / region / month grain, then join back if needed:

region_stats = df.groupby("region").agg(
    region_accidents=("accident_id", "count"),
    region_casualties=("casualties", "sum"),
)
df = df.merge(region_stats, on="region", how="left")

4. Date-Time Feature Extraction

df["date"] = pd.to_datetime(df["date"])
df["year"] = df["date"].dt.year
df["month"] = df["date"].dt.month
df["month_name"] = df["date"].dt.month_name()
df["dayofweek"] = df["date"].dt.dayofweek  # 0=Mon
df["is_weekend"] = df["dayofweek"].isin([5, 6]).astype(int)

Monthly trends (syllabus) often start here, then groupby month for charts (ties to L14).

5. Binning

df["speed_band"] = pd.cut(
    df["speed_limit"],
    bins=[0, 30, 50, 70, 200],
    labels=["Low", "Medium", "High", "VeryHigh"],
)

Bins make continuous risk factors readable on dashboards and support stratified analysis.

6. Practical (Syllabus)

  1. Create year, month, is_weekend from date.
  2. Bin speed_limit into bands; count accidents per band.
  3. Create a severity flag or ratio feature; summarize by region.
  4. (Sales track) If using a sales file: compute revenue and profit margin; monthly trend table.

7. Knowledge Check

Q1. Extracting month and day-of-week from a date column is:

A. Only a visualization theme setting
B. Date-time feature engineering
C. Multicollinearity by definition
D. A form of random deletion

8. Summary

  • Good features encode domain logic: ratios, flags, calendar parts, bins.
  • Aggregation changes grain — be explicit.
  • Syllabus examples: revenue, margin, monthly trends.
