Lecture 21: Power BI Visualization

Build report pages: core visuals, formatting, slicers, edit interactions, and a first publish path — applying everything from L16–L20.

1. Learning Objectives

  • 1 Build standard visuals (bar, line, matrix, card, map) with correct fields.
  • 2 Format titles, labels, legends, and tooltips for clarity.
  • 3 Add slicers and sync them across pages when needed.
  • 4 Control visual interactions (filter, highlight, none).
  • 5 Apply dashboard-thinking layout and publish a report to Power BI Service (overview).

2. Core Visuals in Practice

VisualTypical fieldsTip
Card / multi-cardSingle measureAdd vs target via measure or reference
Bar / columnCategory + measureSort descending for rankings
LineDate hierarchy + measureContinuous axis for time
MatrixRows, columns, valuesStepped layout; expand hierarchy
MapLocation + measureClean location data; size by magnitude carefully
TableDetail columnsUse for exceptions, not primary story

3. Formatting That Matters

  • Title = insight or question, not the field name alone
  • Data labels only when they add value (avoid clutter)
  • Consistent theme colors aligned with categorical/sequential roles
  • Tooltip pages for definitions and extra detail
  • Align and distribute objects; snap to grid

4. Slicers & Interactions

Slicers filter the page (or synced pages). Prefer dropdown or tile for few values; hierarchy slicers for dates/orgs.

Edit interactions: Format → Edit interactions — set whether a visual filters, highlights, or ignores another. Use “None” to stop accidental cross-filter noise.

5. Multi-Page Reports

  • Page 1: Executive summary (KPIs + one main trend)
  • Page 2: Drivers / breakdowns
  • Page 3: Detail or exception table

Sync slicers across pages when the same filters should apply. Name pages for the audience, not “Page 1”.

6. Publish Overview

Desktop → Publish → choose workspace. In Power BI Service: set scheduled refresh (for Import models), share with app or workspace roles, and optionally pin visuals to a dashboard (Service dashboard ≠ report page).

Note
Sharing and capacity depend on your tenant license. Practice layout and interactions fully in Desktop even before Service access.

7. Practical — Mini Sales Report

  1. KPI cards: Total Sales, Orders, Avg Order Value
  2. Line: Sales by Month
  3. Bar: Sales by Category (sorted)
  4. Slicers: Year, Region
  5. Edit interactions so the category bar does not filter the KPI definitions incorrectly
  6. Title the page “Sales performance — current year”

8. Knowledge Check

Q1. How do you stop one visual from filtering another?

A. Delete the model
B. Edit interactions → set to None
C. Remove all slicers permanently
D. Convert to DirectQuery

9. Summary · End of Module 4

  • Choose visuals from the question (L16–L18); layout for decisions (L19).
  • Clean import and model (L20) make visuals trustworthy.
  • Format, slicers, and interactions turn a canvas into a usable report (L21).
