Lecture 23: DAX Basics

Measures vs columns, core aggregation functions, row vs filter context, and your first CALCULATE patterns.

1. Learning Objectives

  • 1 Choose calculated column vs measure for a given need.
  • 2 Write measures with SUM, COUNTROWS, DISTINCTCOUNT, AVERAGE.
  • 3 Explain filter context in plain language.
  • 4 Use CALCULATE to modify filters (simple cases).
  • 5 Avoid common beginner mistakes (summing wrong columns, ignoring context).

2. Calculated Column vs Measure

Calculated columnMeasure
EvaluatedAt refresh, row by rowAt query time, in filter context
StoredIn the model (uses memory)Not stored as values
Use whenRow-level attributes, slicing by new categoriesAggregations, ratios, time intelligence
ExampleFullName = First & " " & LastTotal Sales = SUM(Sales[Amount])
Rule of thumb
Prefer measures for anything that aggregates. Prefer columns when you need a static label per row.

3. Core Aggregation Patterns

Total Sales := SUM ( Sales[Amount] )

Order Count := COUNTROWS ( Sales )

Customer Count := DISTINCTCOUNT ( Sales[CustomerKey] )

Avg Order := DIVIDE ( [Total Sales], [Order Count] )

Use DIVIDE instead of / to handle divide-by-zero safely.

4. Filter Context (Simple View)

When a visual shows Total Sales by Region, each cell has a filter: Region = that region. Measures respect those filters automatically. That is filter context.

Row context appears inside iterators (and calculated columns): the formula “sees” one row at a time.

5. CALCULATE — First Steps

CALCULATE evaluates a measure under modified filters.

Sales Online :=
CALCULATE (
    [Total Sales],
    Sales[Channel] = "Online"
)

Sales All Channels :=
CALCULATE (
    [Total Sales],
    REMOVEFILTERS ( Sales[Channel] )
)

You will deepen CALCULATE in Lecture 24 (filter arguments, ALL, time intelligence).

6. Common Mistakes

  • Creating a calculated column for a total that should be a measure
  • Summing a dimension key or a year number
  • Using implicit measures only (hard to reuse and test)
  • Ignoring blank handling in ratios

7. Knowledge Check

Q1. Total revenue that changes with slicers should be a:

A. Calculated column only
B. Measure
C. Report theme color
D. Folder name

8. Summary

  • Measures aggregate in filter context; columns materialize per row.
  • Start with SUM, COUNTROWS, DISTINCTCOUNT, DIVIDE.
  • CALCULATE changes the filter context of a measure.
