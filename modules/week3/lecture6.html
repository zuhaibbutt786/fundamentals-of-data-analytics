Lecture 6: Outliers & Noise Handling

Detect outliers with Z-score and IQR, understand their impact on analytics, and choose treatment strategies — syllabus practical: boxplot detection.

1. Learning Objectives

  • 1 Define outlier vs noise in analytical terms.
  • 2 Apply Z-score and IQR rules to flag candidate outliers.
  • 3 Explain how outliers distort mean, correlation, and models.
  • 4 Choose treat / transform / keep strategies with business context.
  • 5 Build a boxplot-based outlier report in Python.

2. Outlier vs Noise

  • Outlier — a point that is unusually far from the bulk of the data (may be error or rare truth).
  • Noise — unstructured variation that obscures signal (measurement jitter, typos, sensor glitches).

Never delete “unusual” rows blindly: a multi-casualty crash is an outlier and a critical signal for safety policy.

3. Detection Methods (Syllabus)

Z-score

\[ z_i = \frac{x_i - \bar{x}}{s} \] Common rule: \(|z| > 3\) (or 2.5) flags candidates. Sensitive when the mean/SD are themselves distorted by extremes.

IQR method

\[ \text{Lower} = Q1 - 1.5\times IQR,\quad \text{Upper} = Q3 + 1.5\times IQR \] More robust for skewed data. Boxplots encode the same fences visually.

4. Impact on Analytics

  • Pulls the mean and inflates variance
  • Can dominate correlation and regression slopes
  • Breaks normality assumptions for parametric tests
  • Dashboard KPIs look “wrong” to domain experts if one bad row survives

5. Treatment Strategies

StrategyWhenCaution
Investigate / correctData entry or unit errorsBest first step
Winsorize / capExtreme but plausibleDocument thresholds
Transform (log)Right skew + heavy tailReport in original units later
RemoveProven error; sensitivity analysis OKNever silent deletion
Keep + robust statsTrue rare eventsUse median, IQR, robust models

6. Python — Boxplot & Rules

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

df = pd.read_csv("../../datasets/sample_accidents.csv")
s = df["casualties"]

# IQR fences
q1, q3 = s.quantile(0.25), s.quantile(0.75)
iqr = q3 - q1
low, high = q1 - 1.5 * iqr, q3 + 1.5 * iqr
flags = (s < low) | (s > high)
print("IQR outliers:", flags.sum())

# Z-score
z = (s - s.mean()) / s.std(ddof=1)
print("Z>3 outliers:", (z.abs() > 3).sum())

df.boxplot(column="casualties", by="region")
plt.suptitle("")
plt.title("Casualties by region — boxplot")
plt.show()

7. Practical

  1. Flag IQR and Z-score outliers on casualties and vehicles.
  2. Draw a boxplot by region or severity.
  3. For each flagged row, decide: keep (true event), fix, or remove — with a one-line reason.

8. Knowledge Check

Q1. For a heavily right-skewed variable, prefer first:

A. Only mean ± 1 SD
B. IQR / boxplot fences
C. Dropping half the rows randomly

9. Summary

  • Detect with Z-score and IQR; visualize with boxplots.
  • Impact is real — but rare true events must not be erased silently.
  • Treat with investigate → transform/cap → remove only with documentation.
