# Brag Plan: Fundamentals of Data Analytics

## What is this app?
A complete, free, university-level Data Analytics course (CS 399 style) built as a polished static website with 30 lectures, interactive quizzes, labs, Power BI content, and a modern dark/light glassmorphism UI — entirely self-contained.

## The angle
You didn't take the course. You *wrote* the entire damn course, designed the UI, shipped the interactive site, and made it free for the world. This is educator + engineer flex energy.

## Hook (first 2-3 seconds)
Big gradient text: "30 Lectures." Then the number pops and the rest of the stats (6 Modules · 15 Weeks · 100% Free) slam in. Immediate scale + free claim.

## Key moments (the middle)
- The hero stats bar with the 100% Free & Self-Contained claim
- Clean module cards revealing the full curriculum path (Foundations → Cleaning → EDA → Power BI → DAX → Capstone)
- Glassmorphism UI + dark mode toggle moment
- Quick flash of real lecture content / SVG diagrams

## Outro / punchline
"World-class. Free. Built by one person." → Instructor photo + name + "GIFT University" → Live course URL.

## User flow worth showing
none — landing-page only (static course site). Rely on hero + module overview + visual polish.

## Tone
- Preset: polished
- Creative direction: quiet premium product film meets proud educator flex
- Interpretation: Clean, confident pacing. Elegant typography. Restrained motion. Let the achievement speak. No chaos, no startup parody — this is serious work presented with pride.
