## How to use

1. Download the `.ipynb` file (or open raw on GitHub → Download).
2. **Python labs:** open in Jupyter Lab, VS Code, or [Google Colab](https://colab.research.google.com/).
3. **Power BI labs:** follow the step checklist in Power BI Desktop; use CSVs from [`/datasets`](../datasets/README.md).
4. Point data paths to `../datasets/...` when running next to the repo layout.
