# Course Labs (Jupyter Notebooks)

Downloadable practical labs aligned with the CS-399 Fundamentals of Data Analytics lectures.

| Lab file | Related lecture | Topic |
|----------|-----------------|-------|
| [L2_Python_Basics_Comprehensive_Lab.ipynb](L2_Python_Basics_Comprehensive_Lab.ipynb) | Lecture 2 | Python basics for data science |
| [L3_Data_Acquisition_and_Scraping.ipynb](L3_Data_Acquisition_and_Scraping.ipynb) | Lecture 3 | Data acquisition types & scraping ethics |
| [L3_Python_Data_Structures_Guide.ipynb](L3_Python_Data_Structures_Guide.ipynb) | Lecture 3 | Python data structures + Pandas intro |
| [L4_Analytical_Thinking_Practical_Lab.ipynb](L4_Analytical_Thinking_Practical_Lab.ipynb) | Lecture 4 | Analytical thinking & business framing |
| [L5_Data_Quality_and_Profiling.ipynb](L5_Data_Quality_and_Profiling.ipynb) | Lecture 5 | Data quality dimensions & missing data |

**How to use**
1. Download the `.ipynb` file.
2. Open in Jupyter Lab / VS Code / Google Colab.
3. Run cells in order; complete the exercises marked for students.

Supporting datasets live in [`/datasets`](../datasets/README.md).
