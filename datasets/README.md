# Course datasets and data dictionary

New teaching cases are **synthetic**, generated by `scripts/generate_datasets.py` with NumPy seed 399. No customer or patient records are real. Rerunning the generator reproduces them in the stated software environment; they demonstrate methods, not real business or public-health findings.

### Sales fields

| Field | Meaning / validation |
|---|---|
| OrderID, LineID | Composite order-line key; OrderID repeats across lines. Use distinct OrderID for order count. |
| OrderDate | ISO calendar date; convert to Date and relate to DimDate[Date]. |
| ProductKey, CustomerKey, RegionKey | Foreign keys to unique dimension keys. |
| Product, Category, Region | Convenience labels for Python; use dimensions in the star schema. |
| Quantity | Integer number of units; clean synthetic sales are positive. Dirty negative value is impossible under the no-returns assumption. |
| UnitPrice, UnitCost | USD per unit; fixed within each synthetic product. |
| Discount | Fraction of gross revenue, from 0 to 1. |
| GrossRevenue | Quantity × UnitPrice, USD. |
| NetRevenue | GrossRevenue × (1 − Discount), USD. |
| TotalCost | Quantity × UnitCost, USD. |
| Profit | NetRevenue − TotalCost, USD. |

Margin = sum(Profit)/sum(NetRevenue); average order value = sum(NetRevenue)/distinct orders. No tax, shipping, returns or other expenses are included. Fixed product prices/costs, even daily order counts and generated category preferences simplify the case; do not infer real seasonality, price elasticity or causal effects.

The dirty file is a separate exercise, not input to the clean Power BI case. Preserve it, remove only the exact duplicate, normalize region labels, quarantine invalid quantity/date, flag missing quantity **before** filling, and recompute derived amounts. The large quantity of 100 is deliberately valid. Median imputation is a descriptive baseline with sensitivity analysis; prediction requires training-only fitting. The eight-record visual is a distinct, smaller example whose raw/clean CSVs are in `assets/visuals/`.

### Accident fields

`accident_id` is an identifier, not a measurement. `date` is an ISO date; `region`, `weather`, `road_type`, and `severity` are categories. `speed_limit` is a synthetic speed-limit value in miles/hour; `vehicles` and `casualties` are counts. Severity is generated as Slight/Serious. There are no traffic volumes, person-distance exposures or verified reporting denominators. Counts alone cannot rank real road danger or support policy. No identifying individuals, locations or license plates are included.

## Original course inputs retained

| File | Scope / provenance limitation |
|---|---|
| [sample_sales.csv](sample_sales.csv) | Ten-row simple retail example, January 2024. Suitable for syntax, insufficient for meaningful year-over-year comparisons. |
| [sample_accidents.csv](sample_accidents.csv) | Twenty-row original course sample. Not used to establish real-world incident rates. Source/provenance was not documented in the original repository. |
| [electric_production.csv](electric_production.csv) | 397 monthly observations, January 1985–January 2018; DATE and IPG2211A2N (production index, not energy in kWh). Historical course snapshot. |
| [Electric_Production_analysis.csv](Electric_Production_analysis.csv) | Original companion with extra analysis/forecast columns. Do not treat supplied forecasts as verified predictions or use future-derived columns as predictors. |
| [pima_diabetes.csv](pima_diabetes.csv) | Small Pima-style sample retained for syntax. Some physiological zeros may represent missing measurements; do not turn pregnancies=0 into missing automatically. Not for clinical conclusions. |

The original repository did not record complete upstream versions/licenses. Retained samples should be treated as teaching snapshots; verify provenance and reuse terms before redistributing them as real-source datasets. For a new project use the original publisher, record version/access date and preserve its license. The new synthetic cases avoid reliance on undocumented upstream permissions.
