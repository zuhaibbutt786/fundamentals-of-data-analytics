# Course Datasets

Download these files for labs and exercises.

| File | Description | Used in |
|------|-------------|---------| 
| sample_accidents.csv | Road accident sample (course original) | EDA, Power BI |
| sample_sales.csv | Simple retail sales transactions | Transformation, Feature Eng, Modeling |
| titanic.csv | Classic Titanic passenger data | Missing values, Classification intro, EDA |
| pima_diabetes.csv | Pima Indians Diabetes (no header) | Outliers, Feature Engineering |
| gapminder.csv | Gapminder country indicators over years | Time series, Visualization |
| Electric_Production_analysis.csv | US Electric Production time series | Time Series labs |

All files are ready for `pd.read_csv()`.
