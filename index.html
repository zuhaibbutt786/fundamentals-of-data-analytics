What You Will Master

This course follows a rigorous university-level syllabus (CS 399) while delivering an interactive, industry-grade learning experience. Every concept includes theory, visual explanations, Python & Power BI implementations, labs, quizzes, and interview preparation.

  • Design end-to-end data analytics pipelines (ETL / ELT)
  • Clean, profile, transform, and engineer features with Python & Pandas
  • Perform deep exploratory data analysis and statistical interpretation
  • Build interactive dashboards and data models in Power BI with DAX
  • Communicate insights ethically and effectively
  • Complete a full industry-style capstone project

Course Modules

Module 1 · Weeks 1–2

Data Analytics Foundations & Pipeline

Modern ecosystem, CRISP-DM, pipeline architecture, data acquisition, business framing. Lectures 1–4.
Module 2 · Weeks 3–5

Advanced Data Cleaning & Preprocessing

Quality & profiling, outliers, transformation, feature engineering, validation, ML basics. Lectures 5–10.
Module 3 · Weeks 6–8

Advanced Exploratory Data Analysis

Descriptive statistics, correlation, aggregation, time series, complete EDA case study. Lectures 11–15.
Module 4 · Weeks 9–11

Data Visualization & Storytelling

Principles, advanced charts, dashboard thinking, Power BI import & visualization. Lectures 16–21.
Module 5 · Weeks 12–13

Data Modeling & DAX

Star/Snowflake schemas, DAX fundamentals & advanced patterns, performance, dashboard project. Lectures 22–26.
Module 6 · Weeks 14–15

Capstone Project

End-to-end industry project: proposal, lab, final dashboard, presentation & viva. Lectures 27–30.
